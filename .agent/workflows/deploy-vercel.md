description: how to deploy the application to Vercel automatically
---

To deploy the application to Vercel, simply push the changes to the `main` branch. This triggers Vercel's automatic deployment.

// turbo-all
1. Stage all changes: `git add .`
2. Commit changes with a descriptive message: `git commit -m "Your descriptive message"`
3. Push to the main branch: `git push origin main`

Wait for the Vercel dashboard to show the successful deployment.
